# Plan — Minimal black & white UI (2026-10-09)

## Request
User: "make interface minimal design black and white, remove premium design".
Scope chosen by user: **dashboard + login/signup** (marketing site unchanged); **keep subtle status colors**
(red/green/amber for errors/success/warnings).

## Approach (centralised, no per-page churn)
- `tailwind.config.js`: gray, slate, zinc and every accent palette (primary, blue, indigo, violet, purple,
  fuchsia, pink, sky, cyan, teal, navy) resolve through CSS variables (`rgb(var(--c-<name>-<shade>) / <alpha-value>)`),
  so all utility variants (hover:, dark:, /opacity) follow the variable.
- `globals.css` (generated by scratchpad `gen-mono-theme.js` + `gen-dark-css-mono.js`):
  - `:root` → neutral greys; accents → black primary actions/links/focus.
  - `.dark` → accents become mid greys so white-on-accent buttons still read on near-black.
  - `.light-only` (marketing root) → the original palette, so the public site is unchanged.
  - Dark-mode safety net (from PR #130) regenerated with neutral greys and neutral accent tints.
  - Minimal: quieter shadows, no glassmorphism, flat body background, native controls `accent-color` mono,
    logo rendered monochrome (black on light, white on dark) via CSS filter.
- Sidebar nav icons: all neutral (`text-gray-400`) instead of 29 decorative colors.
- Status palettes (red, green, emerald, amber, yellow, orange, rose, lime) untouched.
